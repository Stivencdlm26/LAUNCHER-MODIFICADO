# FAKEDRINH

FAKEDRINH is an independent, community-maintained desktop launcher based on the Modrinth App source code. This repository contains the customized launcher, its source, and the release workflow used to publish signed updates.

FAKEDRINH is not affiliated with, endorsed by, or sponsored by Rinth, Inc., Mojang Studios, or Microsoft. Modrinth services and APIs may still be used by parts of the application.
