# @modrinth/assets

This package retains the upstream icon and UI asset utilities used by the launcher. The upstream Modrinth branding directory is omitted in this fork as required by COPYING.md; FAKEDRINH-specific views use fakedrinth-logo.svg instead.

The upstream README credits Devin (integrav) for the original Mr Rinth/Rinthbot artwork. Those original files are not included in this repository.

Lucide icons are imported and exported through index.ts and generated by the package tooling. Other custom assets are re-exported manually.
