# FAKEDRINH Desktop Launcher

FAKEDRINH is an independent community fork of the Modrinth App desktop launcher for managing Minecraft instances and mods.

This fork is not affiliated with Rinth, Inc., Mojang Studios, or Microsoft. It retains the upstream package licenses and notices; see the repository and package-level COPYING.md files before redistributing.

Build instructions and the signed Windows release workflow are documented in the root README. Release signing keys must be configured as GitHub Actions secrets and must never be committed.
